# CET-6 六级词汇复习

48天逐日词汇学习资料，覆盖2026年10月26日至12月12日。

- 42天新词学习：每天20词，共840个不同词条。
- 每天5个写作翻译优先词、常用搭配及中译英练习。
- 学后第1、3、7天回顾，并在考前集中复习。
- 支持遮住释义和搭配自测、按日期跳转、打印。

直接打开 `index.html` 即可使用，无需安装依赖。

## GitHub Pages

在仓库 Settings → Pages 中，选择 **Deploy from a branch**，分支选 **main**，目录选 **/(root)**，然后保存。

修改 `index.html` 并推送后，GitHub Pages 会自动更新。`.nojekyll` 用于直接发布静态文件。

词表按六级常见主题和学习实用性编写，并非基于真题语料库统计的频次排行榜；例句均为自编。
