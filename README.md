# CET-6 六级词汇复习

48天逐日词汇学习资料，覆盖2026年10月26日至12月12日。2026年10月27日起按进阶版安排调整。

- 10月26日保留原20词；10月27日至12月6日安排36个40词学习日、5个周复习日，共1460个不同词条（含搭配）。
- 每学习日6个优先运用词及造句任务，另附主题中译英和自编参考句。
- 普通日约30个具体旧词，按约1、3、7天间隔抽取；10月27日衔接复习原20词。
- 11月2、9、16、23、30日不加新词，进行周复习；12月7—11日集中回顾。
- 40词为目标，可按留存率降至25—30词；基础词用于查漏，优先处理抽象学术词、熟词僻义和写译搭配。
- 支持遮住释义和搭配自测、按日期跳转、打印。
- 每日识义分数按当天词量填写：原10月26日为20分，进阶学习日为40分。
- 点击词表序号可标黄或取消整行，生词自动按字母顺序汇总。
- 分数和标记保存在当前浏览器中，刷新后恢复；不跨浏览器、设备或网址同步。
- 月历导航支持10—12月切换，展示每日主题、识义分数、生词数以及复习和考试日期。
- 首页仅显示日历；点击日期只打开对应一天的内容。支持前后日期切换、返回日历和刷新恢复当前日期。
- 生词与学习方法分别从顶部导航进入，避免在首页堆叠全部资料。
- 旧版标黄生词自动保留；只迁移内容未变的10月26日分数，其余旧分数原样保存在浏览器v1记录中，不换算为新版分数。

直接打开 `index.html` 即可使用，无需安装依赖。

## GitHub Pages

在仓库 Settings → Pages 中，选择 **Deploy from a branch**，分支选 **main**，目录选 **/(root)**，然后保存。

修改 `index.html` 并推送后，GitHub Pages 会自动更新。`.nojekyll` 用于直接发布静态文件。

词表按六级常见主题和学习实用性编写，并非基于真题语料库统计的频次排行榜；例句均为自编。
